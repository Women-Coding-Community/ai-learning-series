# Session 6: Loop Engineering: Agents That Run While You Sleep + Demo Day

**Level:** Advanced, community showcase

## Overview

The finale. We've built the harness, now we close the loop. Loop engineering was the shift of June 2026: stop prompting your agent turn by turn, and design the loop that prompts it for you. We'll unpack the difference between equipping a single agent run (the harness) and a self-running cycle (the loop): act, observe, decide, repeat, with a goal and a stopping condition, and why getting that stopping condition right is the hardest part. Then we demo the standup radar: one Skill, one cron line, sub-agents fanning out across your sources, and a finished report waiting before your chai goes cold. We close with Demo Day, where community members show 5 to 10 minutes of how they're using their own harness or agents at work.

## Live Build / Demo

- The "standup radar": one Skill, one cron line, sub-agents fanning out to multiple sources, one HTML report waiting before your chai goes cold
- Patterns: nightly test suite + morning brief, weekly dependency audit, hourly deploy checks
